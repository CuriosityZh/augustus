# Augustus Planning для Apple Silicon

Отдельная сборка Augustus 4.0.0 на базе `7af2ee66fb816145795192c6648a6720e83d284c`.
Исходный проект: https://github.com/Keriew/augustus. Этот fork не является официальным выпуском Augustus.

## Установка

1. Скачайте `Augustus-Planning-macOS-arm64.zip` из Releases этого fork или артефактов успешного запуска **Planning Mode builds** в GitHub Actions.
2. Распакуйте `Augustus Planning.app`. Его можно оставить в отдельной папке или скопировать в Applications рядом с обычным `augustus.app`.
3. При первом запуске выберите папку с оригинальными файлами Caesar III. Они необходимы для Augustus и не входят в сборку.
4. Для пользовательских данных оставьте предложенную отдельную папку Planning. Не выбирайте папку сохранений обычной установки как общую папку данных.

Приложение подписано локальной ad-hoc подписью, без Apple Developer notarization. Если macOS блокирует первый запуск, используйте Finder → правый клик по приложению → «Открыть» либо разрешение в «Системные настройки → Конфиденциальность и безопасность». Не отключайте защиту системы целиком.

Идентификатор приложения: `io.github.CuriosityZh.augustus-planning`.
Отдельные настройки по умолчанию: `~/Library/Application Support/augustus-planning/augustus-planning/`.
Внутри находятся `config`, `savegames`, `scenarios`, `screenshots` и другие штатные папки Augustus.
Обычная установка и её пользовательская папка не заменяются.

## Работа с генпланом

- Кнопка **Plan: OFF / ON** внизу карты включает или выключает планирование. Клавиатура: **Option/Alt + P**.
- Включите режим и выберите сооружение в обычном меню строительства. Клик ставит полупрозрачный голубой план без расходов и без создания игрового здания.
- Дороги, стены и акведуки прокладываются перетягиванием: прямой линией или с прямоугольным поворотом. **Shift** выбирает другой угол маршрута. Это геометрический маршрут; он не обходит препятствия автоматически.
- Жильё и перетягиваемые украшения можно размечать прямоугольником. Мост выбирается по прибрежной водной клетке и измеряется до противоположного берега.
- Обычные клавиши поворота и выбора варианта работают до размещения плана. Чтобы изменить тип или поворот готового плана, удалите его и поставьте новый.
- **Move** (**Option/Alt + M**): кликните по плану, затем по месту назначения. Переносится весь объект. Правый клик отменяет выбор.
- **Erase** (**Option/Alt + E**): кликните по плану или выделите область перетягиванием. Реальные здания не удаляются. Обычный инструмент расчистки в режиме планирования также стирает только планы.
- Правый клик без незавершённого действия возвращает режим размещения; затем можно выбрать другое сооружение.
- **Show plans / Plans hidden** (**Option/Alt + H**) временно скрывает все планы. Скрытые планы по-прежнему сохраняются.
- Кнопка Undo/штатная клавиша отмены во время планирования отменяет последнее изменение генплана; повторное нажатие возвращает его.

После выхода из режима планы остаются на карте. Игровое время продолжает идти с выбранной вами скоростью; планирование не ставит город на паузу автоматически.

При успешном настоящем строительстве любой затронутый план здания исчезает целиком, даже при перекрытии одной клетки. У дорог, стен и акведуков исчезают только затронутые клетки. Мост — единый план. Неудачное строительство сохраняет планы.

Планы — визуальные пометки, а не гарантия допустимости строительства. В частности, они могут отмечать места, где позже потребуется расчистка или иные условия. Они не создают рабочих мест, дорог для пешеходов, водоснабжения, услуг, доходов, расходов или влияния на привлекательность.

## Сохранения

Основной `.svx` использует штатный формат выбранной версии Augustus. Генплан записывается рядом в `имя.svx.planning`.

- Поддерживаются Save, Save As, Quick Save, ежегодное Auto Save и резервные слоты Auto Save.
- Companion записывается через временный файл и атомарную замену. Ошибка записи генплана не меняет результат сохранения города; на экране появляется сообщение.
- При загрузке проверяются версия формата, геометрия, контрольная сумма генплана и SHA-256 **точного содержимого игрового сохранения**.
- Отсутствующий, повреждённый, чужой или устаревший companion игнорируется; город загружается без планов.
- Для переноса города с генпланом копируйте оба файла. Companion можно переименовать вместе с `.svx`, сохранив суффикс `.planning`. Одного совпадения имени недостаточно: игровые байты должны совпадать.
- Если сохранение изменено обычным Augustus, старый companion может перестать подходить. Он не применяется к другой ревизии города.
- Для старой версии Augustus действуют обычные ограничения её собственного формата сохранений. Planning Mode не повышает номер формата и не добавляет данные внутрь `.svx`.

Исходные личные сохранения не нужно переносить на место: скопируйте нужные файлы в отдельную папку Planning либо используйте Load и затем Save As под новым именем. Планирование без сохранения не переживает закрытие игры.

## Обновление

См. [UPDATES.md](UPDATES.md). Каждый день проверяется официальный `master`. При чистом слиянии собирается и тестируется отдельный кандидат. Рабочая ветка и предыдущий выпуск не перезаписываются. При конфликте список файлов появляется в отчёте GitHub Actions.

Для обновления приложения скачайте новую проверенную сборку и замените только `Augustus Planning.app`. Пользовательская папка хранится отдельно.

## Проверки и ограничения

См. [TESTING.md](TESTING.md) и [ARCHITECTURE.md](ARCHITECTURE.md). Интерфейс дополнительных кнопок пока на английском. Эта версия предназначена для macOS ARM64 с мышью и клавиатурой; сенсорные платформы не входят в проверенную поставку. Предел — 26 244 плановых объекта (линейные сети считаются по клеткам).
